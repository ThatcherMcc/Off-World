# Directives (Layer 1)

SOPs in Markdown that define **what to do**.

- **Purpose:** Goals, inputs, tools/scripts to use, outputs, and edge cases.
- **Style:** Natural-language instructions (like for a mid-level employee).
- **Used by:** The orchestrator (AI) reads these and calls the right execution scripts in order.

Do not create or overwrite directives without asking unless explicitly told to. Update directives with learnings (API limits, timing, edge cases) as the system improves.
